# Starboard

Comando base: `/starboard`

## 1. /starboard config

Activa el starboard en un canal

Permiso: `ManageGuild`

| Opción | Tipo | Obligatoria | Opciones fijas |
|---|---|---|---|
| canal | canal | Sí | — |
| minimo | número entero | No | — |

## 2. /starboard apagar

Desactiva el starboard

Permiso: `ManageGuild`

Sin opciones.
